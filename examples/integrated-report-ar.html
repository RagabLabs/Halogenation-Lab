خطوات الحل

  1. توحيد أساس التدفق بالساعة. تُحوّل كتل التغذية بكتل المكونات المولية، وتستخدم الامتدادات kmol/h.
    ni=mi/Min_i=m_i/M_i
  2. الامتدادات المدخلة (kmol/h): 0.8, 0.35, 0.1, 0.02. يجب أن تكون كل كميات الخروج غير سالبة.
  3. CH₄: 1 - 0.8 = 0.2 kmol/h.
  4. CH₃Cl: 0 + 0.8 - 0.35 = 0.45 kmol/h.
  5. CH₂Cl₂: 0 + 0.35 - 0.1 = 0.25 kmol/h.
  6. CHCl₃: 0 + 0.1 - 0.02 = 0.08 kmol/h.
  7. CCl₄: 0 + 0.02 = 0.02 kmol/h.
  8. Cl₂: 2 - 1.27 = 0.73 kmol/h.
  9. HCl: 0 + 1.27 = 1.27 kmol/h.
  10. الكتلة الداخلة = 171.85 kg/h؛ الخارجة = 171.85 kg/h؛ الباقي = 0 kg/h.
    εm=mout−min\varepsilon_m=m_{out}-m_{in}
  11. مجموع المنتجات = 0.8 kmol/h؛ الكتلة = 56.57574 kg/h.
    yi=ni/∑nj,wi=niMi/∑njMjy_i=n_i/\sum n_j,\quad w_i=n_iM_i/\sum n_jM_j
  12. متوسط الكتلة المولية = 70.719675 g/mol.
    M‾=∑iyiMi\overline M=\sum_i y_iM_i
  13. Q = (800 × -101.11891) + (350 × -104.15315) + (100 × -99.96787) + (20 × -85.11597) = -129047.84 kJ/h.
    Q=∑jξjΔrHj∘Q=\sum_j\xi_j\Delta_rH_j^\circ
  14. إجمالي المسترجع = 0.72 kmol/h. يحقق كل مكوّن: التغذية = المسترجع + الفاقد.
    ni,R=rini,ni,L=(1−ri)nin_{i,R}=r_i n_i,\quad n_{i,L}=(1-r_i)n_i
  15. S = n(CH₃Cl) / ξ₁؛ Y = n(CH₃Cl) / n(CH₄,in). تتحقق العلاقة Y = X × S عندما ξ₁ > 0.

النموذج والافتراضات

  • امتدادات التفاعلات يحددها المستخدم. لا يتنبأ النموذج بالحركية أو الاتزان أو التوزيع الفعلي للمنتجات.
  • حالات مرجعية غازية عند 298.15 K. قيم NIST-JANAF تقييم موثّق، ولا تُقدَّم بوصفها الأحدث أو التقييم الأفضل الوحيد.
  • المردود الكربوني = مولات المنتج / تغذية الميثان؛ الانتقائية = مولات المنتج / الميثان المتفاعل. الحرارة عند 298.15 K. يُطبّق الاسترجاع على الكلوروميثانات الأربعة، وتُعرض الغازات الأخرى منفصلة.
  • الحرارة تمثل مساهمة التفاعل عند المرجع الغازي، وليست حمل تبريد فعليًا.
